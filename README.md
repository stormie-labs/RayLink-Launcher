# RayLink Launcher

Лаунчер тестового стенда кооператива RayLink (форк X-Ray) для S.T.A.L.K.E.R. Anomaly / G.A.M.M.A; будет на Tauri.
Сейчас здесь дизайн: бриф `docs/DESIGN.md`, макеты `docs/mockups/`, HTML-прототипы `design/`.
Перерисовать PNG: `powershell -File design/tools/render.ps1`, затем `python design/tools/make_sheet.py`.
